# Line Text (Geode mod, Android)

에디터에 글자를 입력하면 얇은 선 오브젝트를 늘이고 돌려서 그 글씨 모양대로 배치합니다.

## 사용법
1. 에디터 왼쪽 줌 버튼 옆의 파란 **TXT** 버튼
2. 글자 입력 (줄바꿈은 `\n`), 폰트 선택(화살표), 크기와 선 두께(px)
3. **Place** → 화면 가운데에 배치, 되돌리기 한 번으로 취소, 배치 직후 전부 선택됨(색·그룹 지정, 이동)

폰트: Simplex / Duplex / Serif / Script / Gothic (영어, 숫자, 기호)

## 설정
- Line Object ID (기본 211): 선으로 쓸 오브젝트. 판정 없는 네모 데코 추천
- Letter / Line Spacing, Curve Simplify(곡선 단순화 → 오브젝트 수 줄이기), Max Object Scale(긴 선 분할)

## 대상 버전
Geometry Dash 2.2081, Geode 5.11.2
