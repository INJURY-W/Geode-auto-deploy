# Path Builder (지오메트리 대시 Geode 모드, 안드로이드)

에디터 플레이테스트에서 지나간 경로를 기록하고, 그 경로를 기준으로 블럭·가시를 자동 배치하는 모드입니다.

## 동작 방식
1. 에디터에서 **플레이테스트**를 시작하면 자동으로 기록됩니다 (위치, 게임모드, 중력 방향, 바닥 접촉, 클릭, 미니 크기).
   - 죽으면 그 직전까지만 기록됩니다. 새 플레이테스트를 시작하면 이전 기록은 지워집니다.
2. 플레이테스트를 멈추고 왼쪽의 초록색 **AUTO** 버튼을 누르면 배치됩니다.
3. 회색 **SET** 버튼으로 설정 창이 열립니다.

## 배치 규칙
| 모드 | 배치 |
|---|---|
| 큐브·로봇 | 서 있던 곳 아래 발판, 점프한 구간의 출발 지면에 가시 (공중 발판이면 받침 블럭 추가) |
| 볼·스파이더 | 바닥/천장 발판, 중력 전환으로 떠난 면에 가시 (천장 가시는 180° 회전) |
| 쉽·스윙·UFO | 경로 위아래로 여유(margin)를 둔 통로 블럭, 높이가 바뀌는 곳은 벽으로 연결 |
| 웨이브 | 쉽과 같지만 더 좁은 통로 |

모든 블럭과 가시는 **기록된 매 프레임의 플레이어 히트박스와 겹치지 않는지** 검사한 뒤에만 놓입니다. 이미 블럭·가시가 있는 칸은 건드리지 않습니다.
배치된 오브젝트는 **되돌리기 한 번**으로 전부 취소되고, 배치 직후 전부 선택된 상태라 바로 옮기거나 지울 수 있습니다.

## 설정 (SET)
- **Placement Style**: `basic`(기본) / `dense`(가시 빽빽, 통로 좁게) / `blocks-only`(가시 없음) / `tight`(가시만, 격자 무시하고 실제 히트박스에 픽셀 단위로 붙임)
- **Spike Spacing (tight)**: tight에서 가시 사이 가로 간격 (작을수록 촘촘)
- **게임모드별 켜기/끄기**: Cube, Ship, Wave, Ball, UFO
- **Spikes per Jump**: basic에서 점프당 최대 가시 수
- **Spike Clearance**: 가시와 플레이어 사이 여유 거리 (30 = 1칸)
- **Ship/UFO, Wave Corridor Margin**: 통로 위아래 여유 공간
- **Block / Spike Object ID**: 사용할 오브젝트 ID (기본 1 / 8)

## 빌드 방법 (.geode 파일 만들기)
PC나 휴대폰 브라우저에서 할 수 있습니다.
1. GitHub에서 새 저장소(Repository)를 만듭니다.
2. 이 폴더의 파일을 전부 업로드합니다. (`.github/workflows/build.yml` 경로가 그대로 유지되어야 합니다)
3. 저장소의 **Actions** 탭에서 빌드가 끝나기를 기다립니다 (약 5~10분).
4. 완료된 빌드의 **Artifacts → Build Output**을 받으면 안에 `heum.path-builder.geode`가 있습니다.

## 설치
1. 안드로이드에 **Geode 런처**가 설치되어 있어야 합니다.
2. `.geode` 파일을 Geode 모드 폴더에 넣거나, 게임 안 Geode 메뉴에서 파일로 설치합니다.
3. 필요 모드 **Node IDs**는 Geode가 자동으로 받아줍니다.

## 대상 버전
- Geometry Dash **2.2081**, Geode SDK **5.11.2**
- GD가 더 새 버전으로 업데이트되어 Geode가 그 버전을 지원하면, `mod.json`의 `geode`/`gd` 값만 바꿔 다시 빌드하면 됩니다.
